# 赌博陷阱模拟器 · 反诈教育演示

> ⚠️ **本项目是反诈教育演示，不是赌博网站。**
> 页面内所有"筹码"均为虚拟数字，不涉及任何金钱交易，无法充值、无法提现、无法兑换任何实物。

## 这是什么

一个跑在 Cloudflare Pages 上的单页 Web 应用，用来在**安全的虚拟环境**里还原非法网络赌博（如所谓"加拿大28"高频快开）的运作机制：

- 30 秒一期的高频开奖倒计时
- 大小 / 单双赔率 1.95 的盘口
- 筹码、全押、余额跳动等交互
- Web Audio API 合成的下注声、滴答声、老虎机滚动声、破产故障音

目的不是让你"玩"，而是让你在零金钱损失的前提下，**亲身感受**赌盘是如何通过高频刺激、多巴胺反馈和倍投心理，一步步把本金洗到归零的。虚拟筹码归零后，页面会调用 AI 根据你的行为数据生成一段反诈判词。

## 为什么要做这个

"加拿大28"等高频快开玩法在中国大陆属于**非法网络赌博**。绝大多数受害者不是不知道"久赌必输"，而是在真实赌盘的高频刺激下失去了理性判断。本项目用最直接的方式——让你亲自下注、亲自归零——把这个过程浓缩到 5 分钟内。

## 技术栈

- **前端**：单文件 `index.html`（原生 HTML + CSS + JS，Web Audio API 合成音效，无任何音频文件）
- **后端**：Cloudflare Pages Functions（`functions/api/chat.js`），转发到 DeepSeek `chat/completions`
- **部署**：Cloudflare Pages（直连 GitHub 仓库自动部署）

## 本地运行

不需要构建，直接用任意静态服务器打开即可：

```bash
# 方式一：python
python3 -m http.server 8000

# 方式二：node
npx serve .
```

打开 `http://localhost:8000`。

> 注：前端可独立运行。破产页的 AI 判词需要后端 `/api/chat`，本地开发时若无 Cloudflare 环境，会自动 fallback 到内置的本地警示文案。

## 部署到 Cloudflare Pages

1. Fork 或 push 本仓库到你的 GitHub。
2. 在 Cloudflare Pages 连接该仓库，构建命令留空，输出目录设为根目录。
3. 在项目 **Settings → Environment variables** 中添加：
   - `DEEPSEEK_API_KEY` = 你的 DeepSeek API Key（https://platform.deepseek.com/）
4. 部署完成后访问分配的域名即可。
